# 用 Vibe Coding 构建特色鲜明的 Remotion 渲染场景

## 《Vibe Coding 构建自动化视频生产线》EP03 · 渲染场景搭建

---

## 一、开场

怎么构建一个特色鲜明的 Remotion 渲染场景？

**特色不在"让 AI 写更花哨的组件"，而在画面分层。** 把背景、内容、叠层、主持人各自独立成层，按需组合——理解了分层架构，就能指挥 AI 搭出有空间感、有辨识度的场景。

---

## 二、画面分层原理：视频场景就是"从底到顶叠图层"

不管 After Effects、OBS 还是 Remotion，视频场景的本质都一样——**从底到顶叠图层**，每层独立渲染、独立控制透明度和动画。

通用四层模型：

| 层 | 做什么 | 举什么例子 |
| :--- | :--- | :--- |
| 背景层 | 定调子，不承载信息 | 渐变、网格、视频 |
| 内容层 | 讲东西，承载要讲的信息 | 卡片、表格、图表、终端 |
| 叠层 | 辅助理解 | 标题、字幕、角标、高亮 |
| 角色层 | 人格化 | 主持人、数字人 |

为什么分层？改一层不动其他层。换数据只改内容层，背景和主持人不用重做。AI 填配置时只管自己那层，不会互相干扰。

你只需要决定要哪几层、每层用什么风格——剩下交给 AI 填配置。

但分层只是原理，具体怎么落地？看我们这套引擎是怎么做的。

---

## 三、背景层：5 种风格 + 视频轮播

背景层定调子。我们这套引擎内置了 5 种风格，配置里一个字段就能切（`verified`）：

| 风格 | 效果 | 适合什么调子 |
| :--- | :--- | :--- |
| 渐变 | 随时间缓慢变色的漂移流动渐变 | 温暖、柔和 |
| 科技网格 | 暗色科技感网格，随时间缓慢平移 | 硬核、技术 |
| 浮动粒子 | 科技感浮动微光粒子 | 开场、未来感 |
| 视频轮播 | 随机轮播背景视频，叠在渐变上 | 有素材、丰富 |
| 透明 | 不画底，让下层透出 | 主持人占满画面 |

怎么配？全局设一个默认风格，某段想换就单独覆盖。某个场景后面想垫一张图或一段视频，加暗化遮罩就行——遮罩透明度可调，图太亮就压暗，让上面的文字读得清。

背景还有独立的蓝色调配色，不跟内容走——这让整个画面有统一的"全息投影"基底，不管内容层用什么场景组件，背景风格始终一致。

你的决策很简单：想要什么调子？科技风用网格，温暖用渐变，有素材用视频轮播，要让主持人占满画面就用透明。AI 填字段。

背景层搞定了，上面承载信息的内容层呢？EP02 已经讲过"一份配置按 type 自动分发"，这里重点讲怎么选场景和怎么扩展。

---

## 四、内容层：16 种现成场景 + 怎么选

内容层承载你要讲的信息。引擎内置 16 种现成场景（`verified`，完整清单见 `scene-types.json`）：

| 场景 | 什么时候用 |
| :--- | :--- |
| 开场 / 收尾 | 片头大字报 / 片尾 CTA |
| 概念卡 / 要点清单 / 流程图 | 概念拆解 / 平铺要点 / A→B→C 流程 |
| 架构图 | 分层节点 + 连接关系 |
| 表格 / 对比卡 | 多方案矩阵对比 / 两方对照 |
| 时间线 | 按时间/版本推进的事件 |
| 图表 / 核心数字 | 量化数据 / 单个硬指标 |
| 终端 / 截图场景 | 命令+输出演示 / 截图叠光标，不用真录屏 |
| 提示框 / 金句 / 章节分隔 | 避坑提示 / 金句收束 / 段落过渡 |
| 对话窗口 | 模拟用户与 AI 的聊天交互 |

怎么选？按你要讲的内容语义对号入座——讲流程用流程图，讲对比用对比卡，讲架构用架构图，列要点用清单。不需要记组件名，你说"这段讲三层架构"，AI 自动选架构图场景、填好字段。

想加自己的场景？告诉 AI 你要什么效果，AI 写组件 + 注册 + 填配置，你验收。关键纪律：别让 AI 从零发明场景——先看现成的能不能用，不能再用 AI 扩展。

内容层搞定了，但画面还是平的。想要空间感？下一层。

---

## 五、全息屏：把画面贴进 3D 房间屏幕

把平面的 UI 画面"透视贴"到房间里的屏幕位置上——画面从平面变成有空间感（`verified`）。

效果是这样的：UI 先平铺满屏让观众看清内容，然后"飞"进房间屏幕的位置，变成斜贴在屏幕上的全息投影。先平铺再飞入，是为了让观众先读懂内容，再感受空间变化。

你需要提供什么？一张房间背景图或视频，加上屏幕四个角的像素坐标——从素材里量出来。可调参数就两个：全息透明度（让画面半透，像投影）和全息色调（偏蓝偏紫随你）。

没有绿屏素材？跳过这层，背景层 + 内容层 + 主持人已经够用。全息屏是锦上添花，不是必需品。

AI 的工作：你给四角坐标和背景图，AI 填配置块，引擎自动算透视变换——你不需要理解矩阵运算，那是 AI 处理的事。

画面有空间感了，还差一个主持人。下一层。

---

## 六、VRM 主持人：自动镜头切换 + 口型同步

主持人不是每帧重新渲染 3D 模型。引擎渲染一次全身画面，然后按场景类型自动裁切/摆位——一套预设系统（`verified`）。

**自动镜头切换**：讲概念时主持人半身出镜，展示表格时缩到角落，开场时全身站旁边。AI 只填场景类型，镜头自动切好——你不需要手动指定每个镜头。

**口型同步**：用字幕的逐字时间戳驱动口型，每个字对应一个口型形状，不需要读音频波形。字幕说"你好"，主持人的嘴就按"你"和"好"的口型动——和时间轴同步，帧级确定。

**两种模式**：

| 模式 | 画面效果 | 适合什么 |
| :--- | :--- | :--- |
| 角落模式 | 主持人贴角落，内容不透明 | 内容为主、主持人辅助 |
| 占满模式 | 主持人占满画面，内容透明浮在上层 | 主持人为主、内容辅助 |

你的决策：选好 VRM 模型和动画，告诉 AI 用哪种模式。想改某个场景的镜头？单独覆盖那个 cut 的预设就行。AI 填配置，引擎自动切镜头 + 驱动口型。

三层都讲完了，怎么组合起来？

## 七、三层叠加：完整配置 + 指挥 AI 搭你的场景

三层各自独立配置，互不干扰——背景层定调子，全息屏加空间感，主持人加人格。一个配置里同时启用三层，引擎按顺序从底到顶渲染。

指挥 AI 搭场景的路径：

1. **决定要哪几层**——背景 + 内容是最小集；全息屏和主持人是可选增强
2. **选背景风格**——5 种风格对号入座
3. **按内容语义让 AI 填场景配置**——16 种现成场景按语义选
4. **需要主持人？** 加 avatar 配置块，选模式
5. **需要全息屏？** 给房间素材和屏幕坐标，AI 填配置
6. **现成场景不够用？** 让 AI 扩展新场景，你验收

**适合的场景**：模板化讲解 + 数据图表 + 有主持人的教学片 + 全息屏科幻风——这些是配置驱动能搞定的。

**不适合的场景**：
- 实拍真人场景——该拍就拍，引擎不替代摄像机
- 写实对口型数字人——恐怖谷，本项目明确排除
- 高自由度影视特效——交专业工具，硬写既慢又难看

---

## 八、总结

- **画面分层原理**：任何视频场景 = 从底到顶叠图层（背景 → 内容 → 叠层 → 角色）——这是可迁移的通用认知，不限于 Remotion
- **三层实例**：背景层（5 种风格 + 视频轮播）→ 全息屏（透视贴图加空间感）→ VRM 主持人（自动镜头 + 口型同步）
- **核心判断**：特色在分层组合，不在写更花哨的组件；理解了分层，就能指挥 AI 搭自己想要的场景
- **人活如实写**：人决定要哪几层、选风格、给素材（房间背景图、屏幕四角坐标、VRM 模型）；AI 填配置、写扩展组件
- **没编程基础也能复制**：会讲需求、会判断验收，就能指挥 AI 搭场景
